# RecoverSense — Definition of Done

A feature is DONE only when:

## Product
- solves the intended user/problem case
- fits the locked architecture
- does not create unjustified scope

## Engineering
- code implemented
- error handling present
- tests added
- no obvious dead code

## Financial safety
- policy cannot be bypassed
- duplicate action considered
- state freshness considered
- execution is auditable
- verification exists where needed

## Documentation
- important behavior documented
- assumptions labeled
- simulation labeled

## Verification
- targeted tests pass
- manual/demo path verified where appropriate
